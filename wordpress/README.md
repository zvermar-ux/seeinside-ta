# SeeInside Travel – WordPress плагин

Ги синхронизира **организираните тури, настаните, хотелите/апартманите, визите, групите и дестинациите, слајдерот на почетна и чартерите** од SeeInside Travel во WordPress, во реално време.
Формите од сајтот (резервации, хотели со проверка на слободни соби, чартери, барања за визи со документи) одат директно во апликацијата, а клиентот може да го провери статусот.
**Увезената понуда (Aries)** не оди на сајтот.

## Инсталација

1. WordPress → **Plugins → Add New → Upload Plugin** → `seeinside-travel.zip` → Activate.
   Потребно: WordPress 6.2+, PHP 8.0+. Препорачано: **ACF Pro** (полињата се регистрираат автоматски), Elementor Pro.
2. Во SeeInside: **Подесувања → Веб-страници (WordPress)** → додај го сајтот.
   Webhook URL: `https://ВАШИОТ-САЈТ/wp-json/seeinside-travel/v1/webhook`
   (на пр. `https://aries.mk/new2026/wp-json/seeinside-travel/v1/webhook`).
   Кликни на иконата клуч → копирај **API клуч** и **webhook тајна**.
3. WordPress → **SeeInside Travel → Врска** → залепи ги → Зачувај → **Тестирај врска**.
4. **Синхронизација → Започни целосен увоз** (еднаш; ги симнува и сликите).
5. **Приказ и темплејти** → *Креирај Elementor темплејти* (со Elementor Pro) и *Креирај страници*.

Од тој момент секоја промена во SeeInside (зачувување, бришење, деактивирање, нов термин, зафатено место, слика…)
стигнува на сајтот за неколку секунди. На секои 15 минути плагинот дополнително ги проверува промените (`/changes`) за ништо да не промакне.

## Ако хостингот ги блокира врските до апликацијата (режим „push“)

Некои хостинзи (cPanel) не дозволуваат сајтот да се поврзе до апликацијата (тестот истекува, „Diagnose connection“ покажува ❌ за TCP/HTTPS).
Тогаш:
1. Во апликацијата: **Веб-страници (WordPress)** → уреди го сајтот → вклучи **„Веб-страницата не може да се поврзе до апликацијата“**.
2. Во WordPress: **SeeInside Travel → Врска → Начин на поврзување** → втората опција → Зачувај.
3. Во апликацијата кликни на иконата **„Испрати сè на веб-страницата“**.

Во овој режим апликацијата ги праќа податоците и сликите на сајтот при секоја промена, а формите (резервации, визи, проверка на статус,
слободни соби) одат директно од прелистувачот на посетителот до апликацијата.

## Што создава

| Во апликацијата | Во WordPress |
|---|---|
| Организирани тури | `sta_tour` (URL `/aranzmani/…`) |
| Настани | `sta_event` (`/nastani/…`) |
| Хотели и апартмани | `sta_hotel` (`/smestuvanje/…`) |
| Визи | `sta_visa` (`/vizi/…`) |
| Групи и дестинации | таксономии `sta_group`, `sta_destination` (со хиерархија и слика) |
| Тип на тура, категорија настан, тип сместување, содржини, држава | `sta_tour_type`, `sta_event_category`, `sta_hotel_type`, `sta_amenity`, `sta_country` |
| Слајдер на почетна | `[sta_slider]` |
| Чартери | `[sta_charters]` со резервација |
| Last minute | `[sta_last_minute]` |
| Резервации / Календар на зафатеност / Барања за визи | формите на сајтот ги праќаат во апликацијата; `[sta_booking_status]` за проверка |

Сите полиња се **ACF полиња** со исти информации како во апликацијата (МК + EN), со табови: основно, цени и термини, програма,
вклучено, фотографии и видео, last/first minute, SEO, синхронизација. Главната фотографија е **featured image**, галеријата е ACF Gallery.
Целиот запис е и во мета полето `_sta_payload` (JSON).

## Билдери

Плагинот сам препознава: **Elementor Pro** (креира Theme Builder темплејти за поединечна страница и листа), **Elementor**, **Gutenberg/блок тема**,
**Divi, Bricks, WPBakery, Oxygen, Beaver** и класични теми (Tourm). Каде нема темплејт, страницата автоматски се исцртува.
Elementor виџети: *Travel: дел од страница* (19 делови), *листа понуди*, *слајдер*, *пребарување*, *авио пребарување*, *чартер места*, *провери резервација*, *дестинации*.
Шорткодовите (табот *Шорткодови и помош*) работат во секој билдер.

## Јазици

Текстовите се на македонски и англиски; кога страницата е на англиски (Polylang / WPML / јазик на сајтот), се прикажува англиската верзија.
